# Color Clash Academy v3.0

Color Clash Academy is an educational color-matching card game for grades 5–8.

## New in v3.0
- Improved card travel animations for play and draw actions
- Fun match-start intro animation
- Rival character titles and speech bubbles
- Deck styles: Prism Classic, Arcane Glow, Neon Arcade, Pixel Pop, Nature Quest
- House-rule options: draw stacking, draw-until-playable, force-play after draw, 7-0 hand swap/rotation rule
- Adjustable starting hand sizes (5, 7, or 10)
- Existing solo, pass-and-play, tournament, achievements, and question banks preserved

## Files
- `index.html` — playable game
- `TEACHER_QUESTION_BANK.csv` — reviewable question bank
- `README.md` — project information
- `RELEASE_NOTES.md` — release summary

Upload the files to a GitHub repository and enable GitHub Pages to play in the browser.
